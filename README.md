### 🤖 AI-assisted development

I've mostly used **Cursor** and **Claude**. Cursor was my main tool during my AI Engineer internship at Mondaysys, and these days I use Claude for most of my coding and research work.

One of my tasks at the internship was building a job-search web app with FastAPI and Supabase. It had JWT login, a way to track job applications, and a feature that scored resumes against job descriptions. Cursor helped me write a lot of the API endpoints, database queries and authentication code.

I didn't just accept what it produced, though:

- 🔍 I went through the generated code line by line until I understood it.
- 🧪 I tested each endpoint myself, including bad inputs and expired or missing tokens, to see if anything broke.
- 🔐 I checked that queries were parameterised (no SQL injection risk) and that API keys stayed in environment variables, not in the code.
- 👥 My work also went through code review at the company, and I fixed issues and retested before deployment.

For me, AI tools speed up the work, but making sure the code is correct and secure is still my job.
